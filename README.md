# AI-Based People Counting System

# Key Features
- YOLO-based person detection
- Unique ID tracking
- Automatic IN/OUT detection
- Real-time people count
- Emergency alarm with siren
- Mobile alert notifications

#  Keyboard Controls
| F | Full Screen |
| A | Emergency Alarm |
| S | Stop |
| R | Reset |
| Q | Quit |

#  How It Works
Camera → YOLO Detection → Object Tracking → 
Counting Line → IN/OUT Detection → Live Statistics → Alerts

#  Technologies Used
Python | OpenCV | YOLO | Object Tracking

#  Applications
- Smart Buildings
- Schools & Offices
- Shopping Malls & Halls
- Security Surveillance
- Crowd Management

#  Future Scope

- Web-based Monitoring Dashboard
- Database Integration
- Face Recognition
- Multiple Camera Support
- Advanced Multi-Object Tracking
- Remote Surveillance Dashboard
